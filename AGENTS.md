## Design Guidelines
We are using `uniwind`, and `react-native-reusables`.

Available Components in the react native reusable.
```

Alert

Aspect Ratio
Avatar
Badge

Context Menu
Dialog

Hover Card
Input
Label
Menubar
Popover
Progress
Radio Group
Select
Separator
Skeleton
Switch
Tabs
Text
Textarea
Toggle
Toggle Group
Tooltip
```

if you need to implement anything related to any of these components, check the components/ui directory, if it's not there, install it using following command

```sh
pnpm dlx @react-native-reusables/cli@latest add {component_name}
```
